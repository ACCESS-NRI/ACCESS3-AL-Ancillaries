# cable_gridinfo

The `cable_gridinfo` app uses `ants` to convert the land ancillaries generated by the workflow into a [CABLE](https://github.com/CABLE-LSM/CABLE) offline `gridinfo` NetCDF file, on the same grid as the ancillaries. It is only run when `LAND_MODEL` is `CABLE`. The precise steps performed by the task are:

1. Take the grid (and the land points) from the land mask, and compute the area of every grid cell (`area`, m^2).
2. Convert the soil ancillary to the gridinfo soil variables and units: `bch`, `ssat`, `sfc`, `swilt`, `sucs` (m), `hyds` (kg m-2 s-1 to m s-1), `rhosoil` (kg m-3), `css` (J m-3 K-1 to J kg-1 K-1, using `rhosoil`), `cnsd` (W m-1 K-1), `sand`, `silt`, `clay` and `albedo2`.
3. Compress the land cover tile fractions to `iveg` (tile number) and `patchfrac` (fraction) for the non-zero tiles of each cell, largest first. The `patch` dimension is the largest number of non-zero tiles in any cell; unused patches hold the fill value (-1).
4. Write the regridded total LAI climatology as `LAI` (m^2/m^2, 12 months).
5. Set every variable to its fill value outside of land points.
6. Optionally, sample the variables the workflow does not generate (`Albedo`, `Ndep`, `Nfix`, `Pdust`, `Pwea`, `SnowDepth`, `SoilMoist`, `SoilTemp`, `SoilOrder`, `isoil`) from a reference gridinfo file using the nearest neighbour. When no reference is given these variables are omitted, and the omission is reported in the task log.

All units are CF compliant (udunits) strings, e.g. `m3 m-3` rather than `m^3/m^3`. Dimension names (`patch`, `time`, `rad`, `soil`) are written with an index coordinate variable each.

Note that soil points which have no bulk density in the soil ancillary (`rhosoil` of 0) have no `css`, which is masked to the fill value.

## Env Arguments

#### Inputs
* `SOIL_SOURCE`: Soil ancillary (NetCDF), from the `merge_soils` app.
* `VEGETATION_FRACTION_SOURCE`: Land cover tile fractions (NetCDF), from the `ancil_split_grass_types` app.
* `LAI_SOURCE`: Regridded total LAI (NetCDF), from the `regrid_LAI` app. Must contain a `leaf_area_index` variable.
* `LAND_MASK_SOURCE`: Land mask (NetCDF) defining the grid and the land points. Must contain a `land_binary_mask` variable with latitude and longitude bounds.

#### Outputs
* `OUTPUT`: Path to write the gridinfo file to.

#### Parameters
* `REFERENCE_GRIDINFO`: Optional gridinfo file to take the variables which are not generated by the workflow from. Leave empty to omit them.
