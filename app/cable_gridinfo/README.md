# cable_gridinfo

The `cable_gridinfo` app combines the land ancillaries generated by the workflow into a [CABLE](https://github.com/CABLE-LSM/CABLE) offline `gridinfo` NetCDF file, on the grid of the land sea mask. It is only run when `LAND_MODEL` is `CABLE`. The variables, dimensions, data types, units and fill values follow the CABLE gridinfo convention (e.g. `gridinfo_CSIRO_CRU05x05_4tiles.nc`). Every variable is set to its fill value away from land points.

| gridinfo variable | Source |
|---|---|
| `area` | Area of each grid cell of the land sea mask (m^2) |
| `bch`, `ssat`, `sfc`, `swilt`, `sucs`, `cnsd`, `rhosoil`, `sand`, `silt`, `clay` | Soil ancillary (`b`, `sm_sat`, `sm_crit`, `sm_wilt`, `sathh`, `hcon`, `BD`, `T_SAND`, `T_SILT`, `T_CLAY`) |
| `hyds` | Soil ancillary `satcon`, converted from kg m-2 s-1 to m s-1 |
| `css` | Soil ancillary `hcap` divided by `BD`, converted from J m-3 K-1 to J kg-1 K-1 |
| `albedo2` | Soil ancillary `soil_albedo` |
| `Albedo` | Soil ancillary `soil_albedo`, repeated for each of the 3 radiation bands |
| `LAI` | Regridded total LAI monthly climatology |
| `iveg`, `patchfrac` | Land cover tile fractions, compressed to the non-zero tiles of each cell, largest first. The `patch` dimension is the largest number of non-zero tiles in any cell, with unused patches set to the fill value |
| `SoilMoist`, `SoilTemp` | Soil initial conditions, repeated for each of the 12 months |
| `SnowDepth` | Zero everywhere |
| `Ndep`, `Nfix`, `Pdust`, `Pwea`, `SoilOrder`, `isoil` | Sampled from a reference gridinfo, using the nearest non-missing reference point |

The soil initial conditions are only available when `SOIL_INITIAL_CONDITIONS` is enabled. Without them `SoilMoist`, `SoilTemp` and `SnowDepth` are omitted. Likewise, the variables taken from a reference gridinfo are omitted when no reference is given. Each omission, and each variable sourced from the reference gridinfo, is reported in the task log.

## Env Arguments

#### Inputs
* `SOIL_SOURCE`: Soil ancillary (NetCDF), from the `merge_soils` app.
* `VEGETATION_FRACTION_SOURCE`: Land cover tile fractions (NetCDF), from the `ancil_split_grass_types` app.
* `LAI_SOURCE`: Regridded total LAI (NetCDF), from the `regrid_LAI` app.
* `LAND_MASK_SOURCE`: Land sea mask (NetCDF), which defines the grid and the land points.
* `SOIL_INITIAL_CONDITIONS_SOURCE`: Soil initial conditions (NetCDF) with 6 soil layers, from the `functional_soil_initial_conditions` app. Set in `flow.cylc`, empty when `SOIL_INITIAL_CONDITIONS` is off.

#### Outputs
* `OUTPUT`: Path to write the gridinfo file to.

#### Parameters
* `REFERENCE_GRIDINFO`: Optional gridinfo file to sample the variables which are not generated by the workflow from. Leave empty to omit them.
